Solmar Bay — an original open-world crime game for the make.fun gta6-01 bounty. A sun-soaked 3D city of three districts, traffic and pedestrians, cars to steal and drive, a five-star wanted system with responding police and a helicopter searchlight, seven story missions, combat, a HUD with a live minimap, WebAudio sound, and saves in localStorage. Built as static files: no build step, no network requests.

## Run it

```sh
npx tsx serve.ts
```

Then open http://localhost:8000/game/index.html in desktop Chrome.
